# Evidence-first Retrieval (M2.5) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在每次模型调用前做可审计的 retrieval reconcile（含 cache 复用），产出稳定排序的 hits + dedupe report + events，并注入轻量 evidence 指针到 ContextPack。

**Architecture:** 新增 `retrieval` 模块（spec/runner/cache/workspace），在 `session/llm.ts` 调用并在 `ContextPackBuilder` 增加 `evidence_pointers` 段；每次调用生成 `retrievalId`（审计）与 `retrievalCacheKey`（复用），事件链闭环且 artifacts-first。

**Tech Stack:** Bun, TypeScript, Zod, EvidenceWriter, Ripgrep, LSP, Workbench

### Global DoD Checklist

- **协议**：`retrievalId` 为 call‑scoped ULID；`retrievalCacheKey` 基于 `retrievalPlanForKey`（排除 session/message），含 `workspaceFingerprint`。
- **事件链闭环**：每次调用仅一条链路 `retrieval.started` → `retrieval.completed|cache_hit|degraded|timeout|cancelled`。
- **Artifacts**：`retrieval.spec.json` / `hits.json` / `dedupe.report.json` / `errors.json`（若 degraded/timeout/cancelled）。
- **排序与去重**：`score_bps` 统一 0–10000；tie‑break 固定；去重基于“命中文本规范化后 sha256”+重叠去重。
- **预算/取消**：AbortSignal 贯通；超时/取消仍产出部分结果与事件。
- **ContextPack 注入**：仅 `evidence_pointers` 段（摘要计数 + artifacts 指针 + topK 轻量指针）。
- **测试**：不使用 mocks，`cd packages/opencode && BUN_INSTALL=/tmp/bun-install TMPDIR=/tmp bun test`。
