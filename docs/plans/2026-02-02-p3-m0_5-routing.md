# Routing M0.5 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 routing runner 落地并行治理（maxWallClockMs 预算、取消、收敛）并保证事件/证据链不断链。

**Architecture:** 在 `RoutingRunner` 内加入“同 session in-flight 追踪 + 运行级 Abort 管理 + 总预算计时器”，统一控制 worker 生命周期；在 WorkerA 扫描循环中检查 `signal.aborted` 以支持真实取消。事件通过 EvidenceWriter 写入，产物保持稳定路径。

**Tech Stack:** Bun, TypeScript, Zod, EvidenceWriter, AbortSignal

    },

})
